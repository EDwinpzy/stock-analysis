# A 股回测：口径正确的验证框架

**这个技能存在的理由：圆小二项目里，三条被广泛引用的量化结论，两条作废、一条腰斩，全部因为口径错误。**

| 错误 | 后果 |
|---|---|
| 信号日收盘价买入 | 4 条规则中 3 条虚高 1.7–3.7pp，1 条方向反转 |
| 拿涨停日当对照组 | 基准本身是 -0.13%，把所有规则都量成负的 |
| 对照池过小 | 1,592 vs 160,501，效应从 -2.56pp 缩到不显著 |

## 九道必查（写任何回测结论前逐条过）

1. **信号在收盘后才确认？** → 买入价必须用**次日开盘**，不能用当日收盘。
2. **对照组代表"不做这个选择"吗？** → 用**同批股票在同期的随机交易日**，不要用涨停日、信号日或别的股票。
3. **扣了双边成本和最低佣金？** → 佣金 0.025%（最低 5 元）、过户费 0.001%、印花税 0.05%（仅卖出）。10 万本金让 5 元下限生效。
4. **扣了同期市场收益吗？** → 报"超额"时必须做市场中性化，否则 beta 会伪装成 alpha。
5. **有安慰剂基准吗？** → 同股 ±30 交易日内随机买入，这才是真正的"不选股"。
6. **效应量有置信区间吗？** → 4,000 次 bootstrap。CI 含 0 就是不显著，别用"4 个方向一致"代替显著性。
7. **样本去重了吗？** → 按 (股票, 日期) 去重，避免同一信号重复计数。
8. **样本跨周期吗？** → 检查是否集中在某一段行情。若全部在 2025-05~07 的下跌段，数字必然失真。
9. **每个分支都自己算过吗？** → 用 `--check-branches`，确认组间差异不是笔误。

## 快速开始

```bash
# 1. 先跑对照基准，确认你的基准没有系统性偏差
python scripts/bt_control.py --data <行情目录>

# 2. 回测任何规则，双口径并排
python scripts/backtest_rule.py --data <行情目录> --rule boll_cross_up
```

所有脚本在 `scripts/` 下，参数一致。行情目录需为 baostock 格式（`<market_bs>/<交易所>_<代码>.json`）。

**节点标博弈**：-0.21%，相对正确基准 -0.56pp（n=20,752）。

### ⚠️ 无法证实

**卖出/回避纪律**：77 样本 / 16 万对照组，四个持有期 CI **全部含 0**。

## 方法论：为什么这个项目修正了五次

| 次 | 原因 | 影响 |
|---|---|---|
| 1 | 小样本（16 条） | 效应 -12.56pp |
| 2 | 扩样（39 条） | 缩到 -2.56pp |
| 3 | 样本偏向活跃股（109→393 只） | 幅度腰斩 |
| 4 | **口径错误** | **数字变号** |
| 5 | 真实数据推翻假设 | 情绪周期判断仅 2/6 吻合 |

**关键区别**：小样本会在扩样后**收敛到某个值**；口径错误会让数字**变号**。前者是精度问题，后者是方向问题。

**所以：任何回测结论，在写出来之前，必须先问「这个买入价在信号产生的那一刻真的可执行吗」。**

## 提醒用户时

**不要**用"回测证明他很差"来表达结论。他的卖点论述本来就是定性语言，无法编码，回测不出优势不代表直觉没有价值。

**要**说"该结论在可执行口径下无统计证据"。区分"没有证据"和"证明无效"。

**市场有风险，以上是历史数据结论，不构成投资建议。**
