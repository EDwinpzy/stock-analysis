## 一、买入价：为什么必须用次日开盘

**信号来自当天收盘的数据**（收盘价、均线、涨停状态、龙头是否断板）。
收盘价是一天中最后成交的一笔，已包含对当日全部信息的反应。
**用它作为买入价，等于假设你在信号产生之前就已持仓。**

### 实测落差

| 规则 | 收盘买入（旧） | 次日开盘（修正） | 落差 |
|---|---:|---:|---:|
| 连板 2-5 板 | +3.24% | -0.46% | **-3.70 pp** |
| 首板 | +1.71% | -0.03% | -1.74 pp |
| 节点标博弈 | +1.80% | -0.21% | -2.01 pp |
| 布林走平 | +0.40% | +0.43% | **-0.03 pp** |

前三条的落差**完全由买入价造成，与成本无关**。
布林不受影响，因为它的信号不依赖涨停状态。

### 例外

如果信号在**盘中**就能确认（比如 10:00 的分时 W 底），可以用当日 10:00 价格。
但本项目所有语料信号都来自**收盘后复盘**，所以一律用次日开盘。

## 二、交易成本：影响比想象中小

### 2×2 分解（2-5 板，3 日）

| 买入价 | 零成本 | 含成本 |
|---|---:|---:|
| 信号日收盘 | +3.24% | +3.14% |
| 次日开盘 | -0.46% | -0.56% |

**成本只吃掉 0.10–0.13 pp。**

原因：3 个交易日的波动（5-10%）远大于 0.1% 的成本。
**回测中更值得警惕的是成交假设，不是手续费。**

## 三、对照组：最隐蔽的错误

### 实测：不同基准的 3 日净收益（次日开盘，扣成本）

| 基准 | 收益 | 胜率 |
|---|---:|---:|
| 涨停日买入 | **-0.13%** | 43.0% |
| 随机日买入（同批股票） | +0.35% | 49.6% |
| 非涨停日买入（18 万样本） | +0.38% | 49.9% |
| 等权全市场组合 | ≈ +0.25% | — |

**涨停日买入是系统性最差的入场时点之一。**
拿它当基准 = 拿坏策略当标尺，量出所有规则都是负的。

### 正确对照的三种用法

| 用途 | 对照组 |
|---|---|
| 测超额 | 同批股票在**同期的随机交易日** |
| 测 beta 成分 | 同期**等权全市场组合** |
| 测形态特异性 | 同股 **±30 交易日内**随机买入（安慰剂） |

## 四、市场中性化

报"超额"时必须扣除同期市场收益。

```
中性超额 = 个股收益 − 同期等权全市场收益
```

实测（推荐信号）：10 日毛收益 +8.02%，同期市场 +2.36%，
毛超额 +5.66pp，**中性后 +5.66pp**——本次恰好一致，因为个股本身高于市场。
但如果不扣，遇到单边行情就会把 beta 当成 alpha。

## 五、安慰剂与置换检验

### 安慰剂基准

同股 ±30 交易日内随机买入。这是"不选股"的最严格定义。

实测（布林走平，4 日）：
- 规则买入 +0.92%
- 同股邻近日 +0.73%
- **真实超额只有 +0.18pp**（直接对比）
- 股票内随机置换：真实超额 **+0.49pp**，CI [+0.22, +0.76]

两种安慰剂给出的数字不同（+0.18 vs +0.49），因为置换检验严格控制了股票内的时间邻近性。
**报告时用置换检验的结果**（更保守、更可信）。

### 置换检验

在**每只股票内部**打乱信号日期，4,000 次，得到零分布。
真实效应若落在分布之外，则 p < 0.025（95% CI 不含 0）。

## 六、置信区间

用 bootstrap，两侧都重采样，**样本量取较小的一侧**：

```python
nb = 4000
bh = rng.choice(his, (nb, len(his))).mean(axis=1)
bc = rng.choice(ctrl, (nb, len(his))).mean(axis=1)   # 注意：size 用 his 的长度
ci = np.percentile(bh - bc, [2.5, 97.5])
```

**常见错误**：对照池远大于信号样本时，若用对照池的原始长度重采样，CI 会被压成一条线。
必须**两侧都重采样到相同数量**。

## 七、样本去重与周期检查

- **去重**：按 (股票代码, 日期) 去重。同一信号在多个文件里可能重复。
- **周期检查**：统计样本的时间分布。若 80% 集中在某一段行情，必须分层报告。
- **扩样收敛检查**：样本翻倍后，效应量若变化超过 50%，说明仍不稳定。

## 八、连板高度的识别

```python
def limit_pct(code):
    c = str(code)
    if c.startswith(("30", "68")): return 20.0   # 双创
    if c.startswith(("83", "87", "43", "92")): return 30.0   # 北交所
    return 10.0

is_lu = (close / prev_close - 1) * 100 >= limit_pct(code) - 0.3
```

容忍 0.3 个百分点处理四舍五入。
连板计数：连续涨停累计，**断板后归零**（不是衰减）。
