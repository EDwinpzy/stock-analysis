# 圆小二超短交易体系

从 224 篇主贴、75672 条跟帖（2025-05-25 → 2026-09-25）蒸馏出的规则。
每条规则都标注了**证据强度**——这是本体系最重要的元信息。

## 证据强度标记

回答时必须带上标记，不要把未验证的规则说成确定结论。

| 标记 | 含义 |
|---|---|
| ✅ **数据支持** | 回测超额显著，95% CI 不含 0 |
| ⚠️ **部分支持** | 方向对但效应量小，或样本不足以做统计推断 |
| ❌ **数据否定** | 回测显示无优势或负超额 |
| 📖 **仅语料** | 他明确讲过，但没有可编码的机械定义，未回测 |

## 一页版：最小可执行决策顺序

按顺序走，任何一步不通过就停：

1. **情绪周期**——现在处于冰点/修复/高潮/退潮的哪一段？
2. **主线**——哪个题材是当前主线？梯队是否完整？
3. **个股角色**——这个票是龙头、容量、弹性还是补涨？在前排还是后排？
4. **买点**——分歧低吸 / 承接 / 趋势回踩 / 尾盘 / 突破，哪一个成立？
5. **卖点与仓位**——阳线即卖、跌破承接止损、量化时代的额外纪律。

**他 80% 的篇幅是给"跟踪条件"，不是即时买入指令**（观察锚点 : 推荐 = 3.8 : 1）。
用户问"能买吗"时，先确认这是不是他自己认定的买点，而不是他提过的一只票。

| 结论 | 状态 | 数字 |
|---|---|---|
| **推荐信号**（他说买哪只） | ✅ | 5日 +3.75%、10日 +8.02%，市场中性后超额显著，CI 不含 0 |

## 回答这类问题时的注意事项

**1. 他在持续迭代，不是固守规则的人。**
2026-01 推翻自己改"全民龙头战法"、03 更新"主动示弱直接 PASS"、04 承认"量化太多太多…正正得负"。
引用他的结论时带上时间点，不要当成不变的教条。

**2. 定性语言不要强行量化。**
他关于卖点、情绪、该碰不该碰的论述全是定性表达，本就没有机械定义。
强行编码会失败——这就是为什么卖点侧回测不出优势。

**3. 唯一例外值得重视。**
全语料唯一被写成机械规则的地方是 tid `2nHJIdDk8pM`（2025-12-12 技术分析课）：
布林走平 + 突破中轨 + 放量 > 1.5×MA20。这个形态有效。
**当他写下可执行的量化条件时数据支持，用自然语言描述感觉时不支持。**

**4. "备选"不等于"现在买"。**
他的推荐多出现在板块发酵中段。数据仍显示有超额，说明选股能力强于择时能力——
但这不改变"此刻不是最佳入场点"的事实。

## 关键提醒

**市场有风险，以上是历史语料的规律归纳，不构成投资建议。**
所有量化结论基于 2025-04 至 2026-09 的 A 股数据，市场结构变化会失效。
