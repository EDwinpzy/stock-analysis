# 模式与量化模型

## 四类常用参与模式

来源：2jX77Atfu3g｜《卖出山河智能，低吸建设工业！》

| 模式 | 成本位置 | 说明 |
|---|---|---|
| **炸板超预期战法** | 可能买在高点（4-5%） | 承认成本高，需要高确定性 |
| **博弈节点标** | 可能买在高点（4-5%） | ⚠️ 已回测无优势，见 `节点与情绪周期.md` |
| **10日偏离值异动低吸** | 低吸 | 偏离值模型 |
| **强辨识度轮动低吸** | 低吸 | 依赖辨识度 |

**模型只是第一层筛选，不代表所有票都符合审美。**

## 六类量化模型与三套处理体系

按反馈周期分类，**不能混用**：

| 模型类别 | 反馈周期 / 止损条件 |
|---|---|
| 通用短线型 | 次日开盘五分钟定强弱，强则留，弱则走 |
| 3日型 | 3个交易日之内跌破5日线，先走人 |
| 弱启动强承接 | 3个交易日不创新高 → 逐步降低关注 |
| 逻辑量化共振型 | 短期重要均线是否失守 |
| 趋势 / 波段型 | 按事先选择的技术轴（5日/10日/平台线） |
| 炸板型 | 炸板后 0 至负 5 开、烂板次日平开/小绿属**符合预期**，反过来才是不及预期 |

三套处理体系：**定线止损**（跌破均线/平台）、**定量止损**（固定百分比）、**逻辑止损**（原逻辑失效即走）。

**规则 55：量化模型是资金行为筛选器，不是自动选股圣杯。**
模型先过滤，人工再用**市场环境、题材逻辑、标的审美**筛选。

## 规则 51 的关键：止损容忍范围不可扩大

> 「在交易之前，就已经明确自己最多能够承受多少波动，后续无论加仓也好，减仓也好，都不能因为仓位变化而随意扩大自己的容忍范围。」
> 「补仓可以改变你的仓位，但不能改变你最初判断错误的事实。」

**这条是整个仓位管理篇的地基。** 加仓、减仓都不能重新谈判止损线。

## 仓位原则

**规则 49：行情好时有序提高仓位，行情转弱时先降低总风险。**
增量仓位优先给**已盈利、趋势仍健康**的标的，**不向亏损股机械摊平**。
> 出处 2uLH82wLIYH：「当大盘处于上升环境……优先考虑已经盈利、趋势仍然健康的方向，不要惯性地把增量仓位扔进亏损标的里面。」

**规则 50：新题材/新模型用小仓试错。**
只有盘面验证、逻辑清楚和核心走强后才考虑提高关注度。
> 「题材的初级阶段，试错仓位单票10%就足够了」（作者个人账户尺度，不可直接当比例指令）
> 「永远不要满水位。」

**规则 53：限制持仓数、清理长期亏损仓、避免满仓单吊或开超市。**
> 「满仓单吊最可怕的地方……会把人逼到变形。」

## 量化时代的额外纪律

**规则 54：量化加快情绪变化，传统"等连续分歧后再做"的节奏可能被压缩。**
> 出处 2iqzrTMVamN：「量化把延续分歧这一步给省略了，基本都是无缝衔接。」

**他承认自己被量化淘汰过：**
> 出处 2lrQWGNuwKP：「当时受到量化的因素还小，极致弱转强非常好用……现在这种玩法非常少了，已被量化市场淘汰掉。」
> 2026-04：「量化太多太多…正正得负」

**实务含义**：他 2025 年上半年的一些打法在当前环境可能已经失效。引用时务必带时间点。
