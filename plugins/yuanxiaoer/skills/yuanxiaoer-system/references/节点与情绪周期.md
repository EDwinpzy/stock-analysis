# 节点与情绪周期

## 节点：判断依据的频次（129 条含证据的节点语句）

| 依据类型 | 次数 | 说明 |
|---|---:|---|
| **情绪冰点/退潮/修复/高潮** | 44 | 最高频，情绪状态是首要判据 |
| 涨停数/晋级/连板梯队 | 34 | 连板结构 |
| 板块表态（一字/封单/龙头） | 31 | 需核心个股明确表态 |
| 连板高度/空间板 | 24 | 天梯高度变化 |
| 监管/异动/停牌 | 16 | 政策扰动 |
| 龙头断板 | 13 | 高度切换 |
| 指数点位 | 13 | 涨跌家数与关键点位 |
| 成交额/量能 | 11 | 万亿级别变化 |
| 涨跌家数 | 8 | 4000 家上涨或下跌 |
| 炸板率/封单 | 3 | 频率低但权重高 |

**最常见的单一依据是情绪状态（44 次），其次是连板结构（34 次）。指数点位仅 13 次——节点不是看指数突破，而是看情绪和结构。**

节点词出现在 144/224 篇，是全语料被强调最多的概念。

## 节点的三条核心规则

**规则 7：节点有同批次协同效应，旧节点可作风险锚，但不能机械照抄。**
同一批次的票可能共同受情绪能量传递，其后续异动、破位应放进组合观察。反推的用途是缩小观察范围，不是给所有同日个股贴上相同命运。
> 出处 2lrQWGNuwKP：「用园林的诞生节点去反推818首板，该日诞生的票，在826、827这几天就要少碰，因为节点是有协同效应的。」

**规则 8：事件节点可以前置交易预期，但要将"预期日"和"结果确认日"分开记录。**
触发日可能早于新闻兑现，亦可能因延期而落空。**事件催化没有市场响应，不算确认。**

**规则 10：复用历史节点时，复用的是结构条件与观察方法，不是历史涨幅模板。**
> 出处 2lrQWGNuwKP：「现在已经没有龙头的完美丝滑节点了，当下的行情并非适用」；「当时受到量化的因素还小，极致弱转强非常好用……现在这种玩法非常少了，已被量化市场淘汰掉。」

**规则 11：语料没有给出统一的节点数学公式、固定提前天数或固定延后天数。**
可落地的方法是记录候选窗口、关键事件、市场验证条件、确认/失效日期；**不把某个日期本身当作"自动买点"**。

## 情绪周期：冰点 → 修复 → 高潮 → 退潮

### 冰点的判定

**规则 12：冰点要用多项盘面数据交叉判断**——红盘/下跌家数、涨跌停、连板高度与晋级、炸板、量能、核心负反馈。
**一项数据弱不能单独等同于全市场冰点**；若情绪与主线都冷却，证据更强。
> 出处 2s8ZY9mDXEs：「回顾前几轮调整的冰点，无一例外都是市场情绪以及主线板块的双冰。」

**规则 13：情绪温度回到 60 以上，曾被用作"冰点后回到常温"的验证线。**
⚠️ 这**不是**已证明适用于所有周期的阈值。不要反向推导成"低于 60 必然是冰点"。单篇明确阈值，偶发规则。

### 冰点转修复

**规则 14：冰点后的第一脚是试错窗口，不是确认主升。**
参与方向优先找抗跌核心/最强修复方向，**仓位按试错控制**。若恐慌之后核心继续补跌、修复不扩散，冰点转势假设失效，不能因为"跌多了"而不断加仓。
> 出处 2s2q5nqtfw7：「真正舒服的节点，其实在周一冰点后的第一脚试错。」

**规则 15：冰点并不等于隔日必修复。**
若连续冰点后仍低开、核心弱、修复缺席，应把"分歧延续/第三次冰点"列为剧本。这条规则直接针对"总该反弹"的主观惯性。
