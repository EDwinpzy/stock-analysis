# 圆小二体系 · 一页速查

## 决策顺序（任一步不通过就停）

1. **情绪周期**：冰点 / 修复 / 高潮 / 退潮？
2. **主线**：哪个题材？梯队完整吗（前排 + 容量 + 补涨各自有角色）？
3. **个股角色**：龙头 / 容量 / 弹性 / 补涨？前排还是后排？
4. **买点**：分歧低吸 / 承接 / 趋势回踩 / 尾盘 / 突破？
5. **卖点与仓位**：阳线即卖、逻辑失效即走、套利票用套利仓位。

1. **他 80% 篇幅是"跟踪条件"不是买入指令**（观察锚点:推荐 = 3.8:1）。他提过 ≠ 现在该买。

## 回测铁律（详见 yuanxiaoer-backtest 技能）

1. 买入价用**次日开盘**，不用信号日收盘
2. 对照组用**同批股票同期随机日**，不用涨停日
3. 扣双边成本 + 最低佣金
4. 报超额前做**市场中性化**
5. 给**置信区间**，不用"方向一致"代替显著性

> 成本只值 0.1pp，成交假设才值 3.7pp。**别在手续费上纠结，去查买入价。**
