# 圆小二数据接口调研终版

> 生成日期：2026-09-27
> 结论：**历史涨停池无免费接口；全市场日线已用 baostock 打通（5,221 只）**
> 数据：363 个交易日、24,651 个涨停样本

## 摘要

本轮系统调研了 8 类数据源，结论分两半：

**已解决**：全市场个股日线 —— baostock，免费、无限速、5,221 只全部取到、零失败

**未解决**：历史涨停池/连板池 —— **8 个渠道全部失败**，这是硬约束不是没找

| # | 数据源 | 能力 | 结果 |
|---|---|---|---|
| 1 | akshare 新浪源 | 个股/指数日线 | **可用**（但限速 0.5/秒） |

| 3 | `push2ex.eastmoney.com` 直调 | 涨停池 | **仅当天** |

### 1.1 关键限制：东财系全部只留当天

实测 `push2ex.eastmoney.com/getTopicZTPool`：

    20260925  -> 52 条
    20260901  -> 0
    20260801  -> 0

接口存在但历史窗口只有当天。akshare 的 `stock_zt_pool_zbgc_em` 明确报错：

    ValueError: 炸板股池只能获取最近 30 个交易日的数据

### 1.2 连板网：数据质量最高，但有配额

**MCP 服务**（`https://www.lianban.net/mcp`，streamable-http，只读）：

| 工具 | 功能 |
|---|---|
| `get_daily_review` | 当日完整复盘（KPI + 连板天梯 + 题材 + AI 复盘） |
| `get_lhb` | 龙虎榜（含游资席位标注） |
| `get_stock_history` | 个股涨停史与龙虎榜史 |
| `list_trade_dates` | 可查询交易日列表 |

**无需 API Key 即可匿名调用**，但：

| 访问方式 | 覆盖 |
|---|---|
| 匿名 MCP | 最近 5 个交易日 |
| 带密钥 MCP | 最近 30 个交易日 |
| 网页 `/days/<date>.html` | 全历史，**但每日 30 篇上限** |

实测配额响应：

    HTTP 429
    Retry-After: 47180  （约 13.1 小时）
    今日历史复盘浏览已达上限

登录后账号信息显示：**免费版每日 30 篇，VIP 200 篇，SVIP 不限**。

**343 个交易日按每日 30 篇计，需约 12 天累积。**

## 三、GitHub 调研：没有现成数据集

### 3.1 搜索受限

GitHub 未认证 API 配额 60 次/小时，搜索过程中耗尽；浏览器端搜索也返回 0 结果（同一 IP）。

### 3.2 已确认的仓库性质

| 仓库 | 星标 | 性质 |
|---|---:|---|
| `akfamily/akshare` | 22.8k | 接口库，涨停池仍是 30 天限制 |
| `zamhown/limit-up-stock-crawler` | 15 | 爬虫代码，**无数据集** |
| `a805748009/stockLimitUp` | 30 | QMT 量化工具，**无数据集** |

### 3.3 一个判断

**不存在现成的免费历史涨停池数据集。**

这类数据都是爬取的，没有机构会托管一份历史快照。GitHub 上能找到的全是爬虫代码，而爬虫本身受制于数据源的 30 天窗口——**这是上游限制，不是工具问题**。

## 五、结论与建议

### 5.1 已不再需要的付费

`hithink-finance`（同花顺官方，¥ 付费）能提供历史涨停池，但**baostock + 自派生已完全覆盖所需指标**，且免费无限速。**不建议购买。**

### 5.2 剩下的唯一硬缺口

**逐只涨停名单与其涨停原因/题材**。

这需要连板网的 343 天完整累积（约 12 天，每天 30 篇），或购买数据源。

**但这不影响已有结论**——两条核心规则已用全市场日线验证完毕。

### 5.3 不建议的做法

不建议试图绕过连板网的配额。技术上可以（换 IP、注册多号），但：
- 违反服务条款
- 账号可能被封
- 收益有限（现有结论不依赖它）
