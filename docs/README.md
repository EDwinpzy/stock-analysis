## 维护约定

- 修改模型公式或冻结参数时，先更新代码与配置，再同步根 README 和相关使用说明。
- 修改采集或蒸馏流程时，同步更新工作流文档，并保留未验证阶段和成功边界的明确说明。
- `报告/` 与 `work/` 是运行产物或临时工作目录，不作为文档导航的权威来源。
