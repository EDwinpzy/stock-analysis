# A股超短情绪市场温度模型 3.2（独立版）

> 版本：3.2  
> 用途：A股超短/连板生态的日频情绪温度、六阶段、牛熊同景、分歧/一致接缝识别。  
> 设计目标：不直接复刻任何网站的“温度”，而是用可核算的真实收盘数据独立计算。  
> 重要：该模型用于市场状态研究，不构成投资建议。

---

## 1. 总体结构

模型按以下顺序运行：

```text
原始收盘数据
→ 牛熊分组（上证 vs MA250）
→ 同景历史标准化
→ 6大基础因子 F/L/R/A/B/V
→ 基础强度 Q
→ 分歧/一致接缝 J
→ 非线性修正（高潮共振、普跌/跌停/炸板、退潮惯性）
→ 最终市场温度 S
→ Δ1 / Δ2
→ 六阶段状态机
```

六阶段：

```text
修复 → 升温 → 高潮 → 降温 → 退潮 → 冰点 → 修复
```

分歧/一致不是第七阶段，而是阶段之间的“接缝”。

## 3. 股票池口径

建议固定：

- 沪深主板 + 创业板 + 科创板；
- ST、*ST、退市整理剔除；
- 北交所单列，不直接混入主模型；
- 首板/连板/空间统一采用“严格连续涨停”；
- “5天3板、11天6板、反包板”不能替代严格连续板高度。

炸板率：

\[
BombRate_t = \frac{炸板数}{涨停数+炸板数}
\]

如果数据源直接提供炸板率，优先使用数据源收盘定版值。

## 4. 牛熊同景分组

上证收盘为 \(C_t\)，年线为 \(MA250_t\)：

\[
Regime_t =
\begin{cases}
Bull,& C_t \ge MA250_t\\
Bear,& C_t < MA250_t
\end{cases}
\]

注意：**牛熊不是给温度直接+/-分。**

牛熊只用于构建同景历史标准化池。

### 4.1 历史百分位池

对每个交易日 \(t\)：

1. 只使用 **t之前** 的历史数据；
2. 优先取与当日同牛熊状态的历史样本；
3. 最多取最近250个同景交易日；
4. 若同景样本少于60个，则与最近250个全市场历史样本按样本量进行混合；
5. 任何情况下禁止使用未来数据。

经验百分位：

\[
P_t(X)=100\times\frac{\#\{X_i\le X_t,\ i<t\}}{N}
\]

范围0~100。

## 5. 六大基础因子

### 5.1 隔日赚钱反馈 F（34%）

先定义非线性反馈函数：

\[
G(r)=50+50\tanh(r/3)
\]

其中 \(r\) 使用“百分点”。

例如：

- 0% → 50
- +3% → 约88
- -3% → 约12

最终：

\[
F=0.60G(昨连板反馈)+0.40G(昨涨停反馈)
\]

**含义：昨天追强的人今天是否得到正反馈。**

---

### 5.2 连板生态 L（24%）

先计算：

\[
ChainRatio=\frac{连板数}{\max(涨停数,1)}
\]

然后：

\[
L=
0.35P(连板数)
+0.25P(空间)
+0.20P(次高)
+0.20P(ChainRatio)
\]

这样不会因为一个孤立高标就误判整个接力生态很强。

---

### 5.3 风险质量 R（18%）

跌停使用非线性惩罚：

\[
D=100e^{-跌停数/18}
\]

封板质量：

\[
SealRate=1-BombRate
\]

并计算同景百分位：

\[
SealScore=P(SealRate)
\]

最终：

\[
R=0.55D+0.45SealScore
\]

---

### 5.4 进攻扩散 A（15%）

\[
A=0.65P(涨停数)+0.35P(首板数)
\]

涨停权重大于首板，避免重复计权。

---

### 5.5 市场广度 B（6%）

\[
B=100\times\frac{红盘数}{正常交易股票数}
\]

B直接使用0~100百分比，不再二次百分位化。

---

### 5.6 量能确认 V（3%）

先计算相对20日成交额：

\[
VR_t=\frac{Turnover_t}{MA20(Turnover)_t}
\]

再计算历史百分位：

\[
T=P(VR)
\]

量能必须与市场广度联动：

\[
V=
clip\left(
50+\frac{(T-50)(B-50)}{50},
0,100
\right)
\]

含义：

- 放量普涨 → 正确认；
- 放量普跌 → 负确认；
- 缩量上涨 → 确认度有限。

---

## 6. 基础强度 Q

冻结权重：

\[
\boxed{
Q=
0.34F+
0.24L+
0.18R+
0.15A+
0.06B+
0.03V
}
\]

Q的范围约0~100。

---

## 7. 分歧/一致接缝 J

J范围：

\[
-100 \le J \le 100
\]

- 正值：偏向“分歧→一致”
- 负值：偏向“一致→分歧”

总公式：

\[
J=
0.35J_{leader}
+0.25J_{follower}
+0.40J_{promotion}
\]

---

### 7.1 龙头承压 \(J_{leader}\)

#### 完整模式

先计算昨日空间龙今日收益强度：

\[
OpenScore=clip(20\times OpenRet,-100,100)
\]

\[
CloseScore=clip(15\times CloseRet,-100,100)
\]

其中收益率仍按百分点输入。

晋级强度：

\[
AdvanceScore=200\times AdvanceRatio-100
\]

最终：

\[
J_{leader}
=
0.25OpenScore+
0.45CloseScore+
0.30AdvanceScore
\]

#### 无龙头明细的降级模式

如果缺失龙头字段：

\[
J_{leader}
=
50\times clip(Space_t-Space_{t-1},-1,1)
+
0.5\times \Delta P(p3p)
\]

最后clip到[-100,100]。

---

### 7.2 跟风稳定度 \(J_{follower}\)

主要看封板质量的方向：

\[
J_{follower}
=
clip(
P(SealRate_t)-P(SealRate_{t-1}),
-100,100
)
\]

如果有主线题材跟风炸板率，可用主线题材数据替代全市场炸板率。

---

### 7.3 晋级方向 \(J_{promotion}\)

**看方向，不看固定绝对阈值。**

分别计算同牛熊、同板位百分位：

\[
D_{12}=P(p12_t)-P(p12_{t-1})
\]

\[
D_{23}=P(p23_t)-P(p23_{t-1})
\]

\[
D_{3+}=P(p3p_t)-P(p3p_{t-1})
\]

最终：

\[
J_{promotion}
=
0.45D_{12}
+0.35D_{23}
+0.20D_{3+}
\]

---

### 7.4 J标签

| J | 标签 |
|---:|---|
| `>= +30` | 强分歧→一致 |
| `+10 ~ +30` | 弱分歧→一致 |
| `-10 ~ +10` | 无明显接缝 |
| `-30 ~ -10` | 一致→分歧 |
| `<= -30` | 强一致→分歧 |

J不直接作为大权重因子，防止重复计分。

接缝修正：

\[
C_J=1.5\tanh(J/35)
\]

范围约[-1.5,+1.5]。

---

## 8. 市场温度基础映射

基础温度映射：

\[
S_{base}=18+0.87Q
\]

之后再加入非线性修正。

## 9. 非线性修正项

### 9.1 高潮共振奖励

若同时满足：

- \(Q\ge75\)
- \(F\ge90\)
- \(R\ge80\)
- \(A\ge75\)

则：

\[
C_{hot}=+1.5
\]

否则0。

---

### 9.2 普跌广度惩罚

\[
P_{breadth}
=
4\times
clip\left(
\frac{25-B}{15},
0,1
\right)
\]

B低于25后开始明显处罚，B<=10时基本达到上限。

---

### 9.3 跌停惩罚

\[
P_{down}
=
3\times
clip\left(
\frac{跌停数-8}{18},
0,1
\right)
\]

8家以内不额外处罚；极端跌停时最多额外扣3分。

---

### 9.4 炸板惩罚

将炸板率换成百分数 \(BR=100\times BombRate\)：

\[
P_{bomb}
=
3\times
clip\left(
\frac{BR-45}{20},
0,1
\right)
\]

45%以下不额外处罚。

---

### 9.5 高潮→降温修正

如果：

- 昨日阶段 = 高潮
- \(J\le-30\)

则：

\[
P_{cool}=1.5
\]

---

### 9.6 退潮/冰点惯性

若：

- 昨日阶段=退潮 且 \(Q<50\)，或
- 昨日阶段=冰点 且当日未确认修复

则：

\[
P_{inertia}=2.0
\]

否则0。

---

## 10. 修复确认

定义核心四因子变化：

\[
\Delta F,\Delta L,\Delta R,\Delta A
\]

结构动量：

\[
M=
0.35\Delta F+
0.30\Delta L+
0.20\Delta R+
0.15\Delta A
\]

修复确认条件：

1. 昨日阶段为冰点或退潮；
2. \(M\ge5\)；
3. F/L/R/A中至少3项较昨日改善；
4. \(F\ge50\)；
5. \(B\ge20\)。

全部满足，`repair_confirmed = True`。

这样可避免“只有昨日反馈翻正，但全市场仍然极端普跌”时过早认定修复。

---

## 11. 最终市场温度 S

\[
\boxed{
S=
clip(
18+0.87Q
+C_{hot}
+C_J
-P_{breadth}
-P_{down}
-P_{bomb}
-P_{cool}
-P_{inertia},
0,100
)
}
\]

这是3.2独立版的最终温度公式。

## 12. Δ1 与 Δ2

\[
\Delta1_t=S_t-S_{t-1}
\]

\[
\Delta2_t=\Delta1_t-\Delta1_{t-1}
\]

等价于：

\[
\Delta2_t=S_t-2S_{t-1}+S_{t-2}
\]

解释：

- S：位置/热度
- Δ1：方向与速度
- Δ2：加速度、钝化、拐点

---

## 13. 六阶段状态机

阶段不是单纯由S硬切，而是结合前一阶段、S、M、J和因子结构。

建议按以下顺序判定。

### 13.1 修复

如果：

- `prev_phase ∈ {冰点, 退潮}`
- `repair_confirmed = True`

则：

`修复`

---

### 13.2 高潮

若：

- \(S\ge82\)
- \(F\ge85\)
- \(A\ge65\)
- \(R\ge65\)
- \(J>-30\)

则：

`高潮`

---

### 13.3 降温

若：

- `prev_phase = 高潮`
- 且 (`M<0` 或 `J<=-10` 或 `Δ1<0`)

则：

`降温`

---

### 13.4 冰点

若：

- \(S\le55\)
- 且 (`F<55` 或 `B<25` 或 `R<50`)

则：

`冰点`

---

### 13.5 退潮

若满足任一：

- `prev_phase = 降温` 且 `Δ1<0`
- 或 \(S<70\)、\(M\le-5\)，并且 (`F<60` 或 `R<55`)

则：

`退潮`

---

### 13.6 升温

若：

- \(S\ge60\)
- \(M\ge3\)
- \(F\ge60\)
- \(L\ge50\)

则：

`升温`

---

### 13.7 其余情况

采用“阶段保持”原则：

- 前一阶段若仍未出现明确反转条件，维持前一阶段；
- 若无历史阶段可用，按S初始化：
  - S<=55 → 冰点
  - 55<S<70 → 修复/升温观察
  - 70<=S<82 → 升温
  - S>=82 → 高潮候选

## 17. 实现注意事项

1. **历史标准化严禁未来函数**：t日只能使用t-1及更早数据。
2. 使用滚动同景池，而不是永久固定阈值。
3. 2025与2026涨停数量中枢不同，因此涨停/首板必须做历史百分位。
4. 牛熊分组不是温度加减项，而是历史比较口径。
5. “分歧→一致”只能用于收盘后确认，不是盘前预测。
6. J只做小幅结构修正，避免与炸板/晋级/空间重复计权。
7. 如果20cm/10cm混合较多，可将收益反馈除以对应涨停幅度后再计算。
8. 昨日涨停/连板反馈建议优先使用**中位数**，不要用普通均值。
9. 若样本量过小：
   - 同景样本<60时进行全样本混合；
   - 1进2/2进3分母过小（如<3）时降低该项权重或沿用前值。
10. 每次修改公式后必须重新做时间序列回测，不允许用未来日期反向调参。

## 18. 建议的历史验证切分

若使用2025~2026数据：

```text
训练/标定：
2025全年 + 2026-01~2026-06

验证：
2026-07~2026-08

样本外：
2026-09起
```

不要随机打乱，因为情绪是时间序列。

## 19. 模型定位

这不是指数择时模型，而是：

**A股超短、打板、连板、强势股生态的日频情绪状态模型。**

因此优先级是：

1. 隔日赚钱反馈
2. 连板生态 / 晋级方向
3. 跌停、炸板等亏钱效应
4. 涨停/首板扩散
5. 市场广度
6. 量能

新高/新低家数不进入核心温度。
