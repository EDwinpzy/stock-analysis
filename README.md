# A股超短情绪温度模型 3.2

> 版本：`A-SHORT-SENTIMENT-3.2`
> 用途：A股超短/连板生态的日频情绪温度、六阶段、牛熊同景、分歧/一致接缝识别。
> 设计目标：不直接复刻任何网站的"温度"，而是用可核算的真实收盘数据独立计算。
> 重要：该模型用于市场状态研究，不构成投资建议。

本仓库把 3.2 版模型从「完整包」落地成一个可直接运行、可测试、可被其他项目调用的
Python 项目，并提供当初约定的 `EmotionEngine` 接口。

# 一、模型方法

## 1. 总体结构

```text
原始收盘数据
→ 牛熊分组（上证 vs MA250）
→ 同景历史标准化
→ 6大基础因子 F/L/R/A/B/V
→ 基础强度 Q
→ 分歧/一致接缝 J
→ 非线性修正（高潮共振、普跌/跌停/炸板、退潮惯性）
→ 最终市场温度 S
→ Δ1 / Δ2
→ 六阶段状态机
```

六阶段：

```text
修复 → 升温 → 高潮 → 降温 → 退潮 → 冰点 → 修复
```

分歧/一致不是第七阶段，而是阶段之间的"接缝"。

## 2. 输入字段

### 2.1 必填基础字段

| 字段 | 含义 | 建议口径 |
|---|---|---|
| `date` | 交易日 | YYYY-MM-DD |
| `sh_close` | 上证指数收盘 | 收盘值 |
| `sh_ma250` | 上证250日均线 | 收盘MA250 |
| `tradable_count` | 正常交易股票数 | 剔除停牌；建议剔除ST/退整 |
| `advance_count` | 红盘/上涨家数 | 收盘涨幅>0 |
| `turnover` | 全市场成交额 | 沪深A股；单位保持一致 |
| `limit_up` | 收盘涨停家数 | 非ST，严格收盘涨停 |
| `limit_down` | 收盘跌停家数 | 同一股票池 |
| `first_board` | 首板家数 | 当日涨停 - 严格连续连板 |
| `consecutive` | 严格连续连板家数 | 2板及以上 |
| `space` | 最高严格连续板高度 | 不使用"N天M板" |
| `next_space` | 次高严格连续板高度 | 无则0 |
| `bomb_rate` | 炸板率 | 0~1，小数形式 |
| `yday_limitup_ret` | 昨日涨停股今日反馈 | 百分点，如+4.53填4.53 |
| `yday_lianban_ret` | 昨日连板股今日反馈 | 百分点 |
| `p12` | 1进2晋级率 | 0~1 |
| `p23` | 2进3晋级率 | 0~1 |
| `p3p` | 3板以上晋级率 | 0~1 |

### 2.2 龙头接缝的增强字段（可选，推荐）

| 字段 | 含义 |
|---|---|
| `prev_leader_open_ret` | 昨日最高板/空间龙今日开盘收益率，百分点 |
| `prev_leader_close_ret` | 昨日最高板/空间龙今日收盘收益率，百分点 |
| `prev_leader_advance_ratio` | 昨日最高板组今日成功晋级比例，0~1 |

三项同时存在时走"完整模式"；缺失时自动降级为 `space` 变化 + 高位晋级率变化。

## 3. 股票池口径

- 沪深主板 + 创业板 + 科创板；
- ST、*ST、退市整理剔除；
- 北交所单列，不直接混入主模型；
- 首板/连板/空间统一采用"严格连续涨停"；
- "5天3板、11天6板、反包板"不能替代严格连续板高度。

炸板率：

```
BombRate(t) = 炸板数 / (涨停数 + 炸板数)
```

数据源直接提供炸板率时，优先使用数据源收盘定版值。

## 4. 牛熊同景分组

```
Regime(t) = Bull  若 Close(t) >= MA250(t)
          = Bear  若 Close(t) <  MA250(t)
```

**牛熊不是给温度直接 +/- 分。** 只用于构建同景历史标准化池。

历史百分位池规则：

1. 只使用 t **之前** 的历史数据；
2. 优先取与当日同牛熊状态的历史样本；
3. 最多取最近 250 个同景交易日；
4. 同景样本少于 60 个时，与最近 250 个全样本按样本量混合；
5. 任何情况下禁止使用未来数据。

```
P_t(X) = 100 × #{X_i <= X_t, i < t} / N
```

## 5. 六大基础因子

### 5.1 隔日赚钱反馈 F（34%）

```
G(r) = 50 + 50·tanh(r / 3)          r 为百分点

F = 0.60·G(昨连板反馈) + 0.40·G(昨涨停反馈)
```

0% → 50；+3% → 约 88；-3% → 约 12。含义：昨天追强的人今天是否得到正反馈。

### 5.2 连板生态 L（24%）

```
ChainRatio = 连板数 / max(涨停数, 1)

L = 0.35·P(连板数) + 0.25·P(空间) + 0.20·P(次高) + 0.20·P(ChainRatio)
```

避免一个孤立高标把整个接力生态算得很热。

### 5.3 风险质量 R（18%）

```
D = 100·e^(-跌停数 / 18)
SealRate = 1 - BombRate

R = 0.55·D + 0.45·P(SealRate)
```

### 5.4 进攻扩散 A（15%）

```
A = 0.65·P(涨停数) + 0.35·P(首板数)
```

### 5.5 市场广度 B（6%）

```
B = 100 × 红盘数 / 正常交易股票数
```

直接使用，不再二次百分位化。

### 5.6 量能确认 V（3%）

```
VR(t) = Turnover(t) / MA20(Turnover)(t)
T = P(VR)

V = clip( 50 + (T-50)(B-50)/50 , 0 , 100 )
```

放量普涨 → 正确认；放量普跌 → 负确认；缩量上涨 → 确认度有限。

## 6. 基础强度 Q

```
Q = 0.34F + 0.24L + 0.18R + 0.15A + 0.06B + 0.03V
```

## 7. 分歧/一致接缝 J

```
J = 0.35·J_leader + 0.25·J_follower + 0.40·J_promotion      ∈ [-100, 100]
```

正值偏向"分歧→一致"，负值偏向"一致→分歧"。

### 7.1 龙头承压 J_leader

完整模式：

```
OpenScore    = clip(20 × OpenRet, -100, 100)
CloseScore   = clip(15 × CloseRet, -100, 100)
AdvanceScore = 200 × AdvanceRatio - 100

J_leader = 0.25·OpenScore + 0.45·CloseScore + 0.30·AdvanceScore
```

降级模式（无龙头明细）：

```
J_leader = clip( 50·clip(Space_t - Space_{t-1}, -1, 1) + 0.5·ΔP(p3p) , -100, 100 )
```

### 7.2 跟风稳定度 J_follower

```
J_follower = clip( P(SealRate_t) - P(SealRate_{t-1}) , -100, 100 )
```

### 7.3 晋级方向 J_promotion

看方向，不看固定绝对阈值：

```
D12 = P(p12_t) - P(p12_{t-1})
D23 = P(p23_t) - P(p23_{t-1})
D3+ = P(p3p_t) - P(p3p_{t-1})

J_promotion = 0.45·D12 + 0.35·D23 + 0.20·D3+
```

### 7.4 J 标签与接缝修正

| J | 标签 |
|---:|---|
| `>= +30` | 强分歧→一致 |
| `+10 ~ +30` | 弱分歧→一致 |
| `-10 ~ +10` | 无明显接缝 |
| `-30 ~ -10` | 一致→分歧 |
| `<= -30` | 强一致→分歧 |

```
C_J = 1.5·tanh(J / 35)        范围约 [-1.5, +1.5]
```

J 只做小幅结构修正，不与炸板/晋级/空间重复计权。

## 8. 温标映射

```
S_base = 18 + 0.87·Q
```

## 9. 非线性修正项

| 项 | 条件 | 取值 |
|---|---|---|
| 高潮共振 `C_hot` | `Q>=75 且 F>=90 且 R>=80 且 A>=75` | +1.5 |
| 普跌广度 `P_breadth` | — | `4·clip((25-B)/15, 0, 1)` |
| 跌停 `P_down` | — | `3·clip((跌停数-8)/18, 0, 1)` |
| 炸板 `P_bomb` | — | `3·clip((100·BombRate-45)/20, 0, 1)` |
| 高潮转冷 `P_cool` | 昨日阶段=高潮 且 `J<=-30` | 1.5 |
| 退潮/冰点惯性 `P_inertia` | 昨日=退潮且`Q<50`，或昨日=冰点且未确认修复 | 2.0 |

## 10. 修复确认

```
M = 0.35·ΔF + 0.30·ΔL + 0.20·ΔR + 0.15·ΔA
```

`repair_confirmed = True` 需要同时满足：

1. 昨日阶段为冰点或退潮；
2. `M >= 5`；
3. F/L/R/A 中至少 3 项较昨日改善；
4. `F >= 50`；
5. `B >= 20`。

避免"只有昨日反馈翻正、但全市场仍然极端普跌"时过早认定修复。

## 11. 最终市场温度 S

```
S = clip( 18 + 0.87Q + C_hot + C_J
          - P_breadth - P_down - P_bomb - P_cool - P_inertia,
          0, 100 )
```

## 12. Δ1 与 Δ2

```
Δ1(t) = S(t) - S(t-1)
Δ2(t) = Δ1(t) - Δ1(t-1) = S(t) - 2S(t-1) + S(t-2)
```

- S：位置/热度；Δ1：方向与速度；Δ2：加速度、钝化、拐点。

## 13. 六阶段状态机

阶段不是由 S 硬切，而是结合前一阶段、S、M、J 和因子结构，按以下顺序判定：

| 顺序 | 阶段 | 条件 |
|---:|---|---|
| 1 | 修复 | `prev ∈ {冰点, 退潮}` 且 `repair_confirmed` |
| 2 | 高潮 | `S>=82 且 F>=85 且 A>=65 且 R>=65 且 J>-30` |
| 3 | 降温 | `prev = 高潮` 且 (`M<0` 或 `J<=-10` 或 `Δ1<0`) |
| 4 | 冰点 | `S<=55` 且 (`F<55` 或 `B<25` 或 `R<50`) |
| 5 | 退潮 | (`prev = 降温` 且 `Δ1<0`)，或 (`S<70 且 M<=-5` 且 (`F<60` 或 `R<55`)) |
| 6 | 升温 | `S>=60 且 M>=3 且 F>=60 且 L>=50` |
| 7 | 其余 | 阶段保持；无历史阶段时按 S 初始化 |

无历史阶段时的初始化：`S<=55` 冰点；`55<S<70` 修复；`70<=S<82` 升温；`S>=82` 高潮。

## 14. 温度等级标签（仅展示）

| 阶段 | 区间 | 标签 |
|---|---|---|
| 冰点 | `<35` / `35~45` / `45~55` | 极限冰点 / 深度冰点 / 冰点 |
| 高潮 | `82~90` / `90~97` / `>=97` | 高潮 / 强高潮 / 极限高潮 |
| 升温 | `60~70` / `70~80` / `>=80` | 主升一级 / 主升二级 / 主升三级 |
| 退潮 | `60~70` / `50~60` / `<50` | 一级退潮 / 二级退潮 / 三级退潮 |

`S<=55` 且冰点条件成立时优先显示"冰点"，而不是"退潮三级"。

## 15. 动能标签（Δ1 + Δ2）

| 条件 | 标签 |
|---|---|
| `Δ1>=5 且 Δ2>=5` | 上攻加速 |
| `0<Δ1<5 且 Δ2>=5` | 向上拐点 |
| `Δ1>0 且 Δ2<=-5` | 上涨钝化 |
| `Δ1<=-8 且 Δ2<=-5` | 退潮加速 |
| `Δ1<0 且 Δ2>=5` | 下跌收敛/退潮衰竭 |
| `Δ1<0 且 Δ2<=-5` | 转弱加速 |
| 其他 | 动能平稳 |

```text

```

# 三、个股评分的环境权重（扩展层）

`config/environment_weights.json` 把"市场阶段 + 接缝"映射成个股评分前的一道乘数。
**这是 3.2 核心模型之外的扩展层，不影响 `core.py` 的冻结公式。**

风格标签：`leader`（龙头/空间龙头）、`high_relay`（高位接力/连板追涨）、
`low_first`（低位首板）、`theme`（题材强度）、`oversold`（超跌修复）、
`defensive`（防守/低波动）、`ice_repair`（冰点修复候选）。

阶段乘数：

| 阶段 | leader | high_relay | low_first | oversold | defensive |
|---|---:|---:|---:|---:|---:|
| 高潮 | 1.18 | 1.05 | 0.95 | 0.85 | 0.85 |
| 升温 | 1.12 | 1.05 | 1.00 | 0.92 | 0.92 |
| 修复 | 1.05 | 0.95 | 1.10 | 1.10 | 1.00 |
| 降温 | 0.98 | 0.85 | 1.05 | 1.05 | 1.05 |
| 退潮 | 0.90 | 0.72 | 1.12 | 1.15 | 1.15 |
| 冰点 | 0.88 | 0.68 | 1.08 | 1.12 | 1.18 |

规则：

1. 多风格按权重做**几何混合**，避免同一只票被重复加成；
2. 接缝 J 另外给 `±0.08` 的倾斜（J 越正越偏向龙头/接力/题材）；
3. 冰点阶段只有同时满足 `S<=55`、`J>=10`、晋级方向改善、龙头未承压，
   才把 `ice_repair` 提升为 `1.25` 倍；
4. 总乘数强制限幅在 `[0.7, 1.3]`——环境可以改变排序，但不能主导评分。

用法（2026-09-11，冰点｜弱分歧→一致）：

```python
state = engine.get_market_state("2026-09-11")

# 低位首板 + 超跌修复：被环境抬到 78.7
engine.adjust_stock_score(72.0, {"low_first": 1.0, "oversold": 0.5}, state=state)
# {'adjusted_score': 78.71, 'multiplier': 1.093,
#  'breakdown': {'low_first': 1.08, 'oversold': 1.12},
#  'notes': ['接缝：弱分歧→一致']}

# 高位接力：同一环境下被压到 50.9
engine.adjust_stock_score(72.0, {"high_relay": 1.0}, state=state)
# {'adjusted_score': 50.86, 'multiplier': 0.706, ...}

# 冰点修复候选：条件全部成立，拿到 1.25 倍加成后被限幅在 1.30
engine.adjust_stock_score(72.0, {"ice_repair": 1.0}, state=state)
# {'adjusted_score': 93.6, 'multiplier': 1.3,
#  'notes': ['接缝：弱分歧→一致', '满足冰点修复条件', '乘数已限幅到 1.30']}
```

同一只 72 分的票，冰点里做低位修复比做高位接力高出约 28 分——这正是"环境因子"
要表达的东西。

| `test_reference_matches_bit_for_bit` | 与完整包 `reference_impl.py` 逐日逐列比对 |

两条口径测试最关键：

- **与冻结实现完全一致**：`emotion/core.py` 跑 400 天面板，与完整包
  `reference_impl.py` 的全部 22 个数值列最大绝对差为 **0.0**，六阶段、

- **无未来函数**：`t` 日结果只依赖 `t-1` 及更早数据，面板截断后历史数值
  逐列完全一致。

# 五、已知行为与注意事项

1. **修复判定优先于高潮判定。** 状态机按第 13 节顺序执行，`repair_confirmed`
   为真时直接返回"修复"。因此在冰点/退潮次日出现强反弹时（例如自带面板
   2026-09-07，S=90.1），模型给出的是"修复"而不是"高潮"。这与参考实现
   完全一致；若要改成"高温优先判高潮"，需要同步更新回归基准。
2. **历史标准化严禁未来函数**：`t` 日只能使用 `t-1` 及更早数据。
3. 使用滚动同景池，而不是永久固定阈值。
4. 2025 与 2026 涨停数量中枢不同，涨停/首板必须做历史百分位。
5. 牛熊分组不是温度加减项，而是历史比较口径。
6. "分歧→一致"只能用于收盘后确认，不是盘前预测。
7. 20cm/10cm 混合较多时，可将收益反馈除以对应涨停幅度后再计算。
8. 昨日涨停/连板反馈建议优先使用**中位数**，不要用普通均值。
9. 样本量过小：同景样本 <60 时进行全样本混合；1进2/2进3 分母 <3 时降低该项
   权重或沿用前值。
10. 每次修改公式后必须重做时间序列回测，不允许用未来日期反向调参。

# 六、历史验证切分建议

```text
训练/标定：2025 全年 + 2026-01 ~ 2026-06
验证：      2026-07 ~ 2026-08
样本外：    2026-09 起
```

不要随机打乱，因为情绪是时间序列。

# 七、模型定位

这不是指数择时模型，而是 **A股超短、打板、连板、强势股生态的日频情绪状态模型**。

优先级：

1. 隔日赚钱反馈
2. 连板生态 / 晋级方向
3. 跌停、炸板等亏钱效应
4. 涨停/首板扩散
5. 市场广度
6. 量能

新高/新低家数不进入核心温度。
